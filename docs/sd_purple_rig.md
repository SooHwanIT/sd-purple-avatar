# SD 보라 캐릭터 — 전신 2D 리그 (model_sd_purple)

2026-11-01. 그림 한 장(`source/vtuber/sd_purple/ref.webp`, SD 정면 T자세)을 부위 레이어로 나누고, 앱 안에서 직접 움직이는 전용 런타임(`avatar/public/js/chibi_rig.js`, `model.type: "chibi"`)으로 리깅했다.

## 왜 이 방식인가

- 그림이 단색 면 + 굵은 외곽선의 SD 그림이라, 가려진 부분(앞머리 밑 이마, 눈 감을 때 드러나는 눈꺼풀, 팔 밑 재킷 어깨, 재킷 밑 바지)을 단색으로 깔끔하게 채울 수 있다. 원본과 다시 합성했을 때 평균 차이 0.24(0~255).
- v9~v11 의 어색함은 실사풍 그림 + 각도별 그림이 없는 것이 원인이었다. SD 그림은 2D 리그가 원래 표준이라 같은 문제가 훨씬 작다.
- Cubism 은 Editor 창을 화면에 띄워 아틀라스·moc3 를 내보내야 하고(게임 중 방해), 체험판 만료 위험이 있다. VRM 은 이 캐릭터의 3D 모델이 없다(VRoid 미설치, 굵은 선 그림체 재현이 어렵다).
- 자체 런타임은 화면을 띄우지 않고 보이지 않는 크롬으로 검수할 수 있고, 한 프레임 계산이 약 1.4ms(정점 1.4만 개)다.

## 부위 나누기 규칙 (지키면 잔상이 안 생김)

- 선의 주인은 "앞에 그려지는 부위"(그리는 순서 `ORDER` 의 뒤쪽). 작은 장식(귀걸이·브로치·목걸이·체인·눈꺼풀·눈썹)은 자기 외곽선을 다각형으로 직접 가져가고 주변 선을 빼앗지 않는다(`NO_GRAB`).
- 머리카락 안쪽 선은 닫혀 있지 않아 영역으로 다발을 나눌 수 없다 → 머리카락은 한 장(`hair`) + 얼굴 뒤 어두운 채움(`hair_back`). 머리 돌림은 정점마다 깊이(둥근 지붕)로, 흔들림은 다발별 휨(뿌리→끝 무게)으로 한 장 안에서 매끈하게.
- 가려진 부분 채우기는 "원래 그림에서 이 부위보다 앞 부위에 가려진 곳"에만(`Layer.allow`). 배경·뒤 부위 자리에 칠하면 그대로 보인다.
- 얇은 띠(안티에일리어싱) 영역은 머리카락으로 가져가지 않는다(두께 3px 미만 → 가장 가까운 부위). 눈 둘레의 어두운 가장자리 → 눈꺼풀, 밝은 가장자리 → 얼굴.
- 얼굴 피부는 전부 같은 번진 색으로 통일(원본의 미세한 얼룩과 채운 곳 경계가 움직일 때 비침). 눈가 분홍 톤도 재료에 넣어야 눈 감은 자리가 하얗게 뜨지 않는다.
- 눈꺼풀 띠 윗부분이 앞머리 끝을 덮고 있어, 띠 뒤에 앞머리 끝(`hair_under`, 뾰족한 다발)을 그려 둔다. 띠와 맞닿은 머리카락 가장자리 3px 는 선 색으로(원래 선이 검은 띠와 합쳐져 있었음).
- 가장자리 반투명 픽셀을 앞 부위로 옮길 때는 실제로 맞닿은(4px) 곳만, 머리카락은 굵은 몸통 근처만. 아니면 멀리 있는 입 둘레·띠 윗선이 머리카락 레이어로 가서 점선 자국이 남는다. 띠 윗선에 붙은 가는 '머리카락' 선은 눈꺼풀로.
- 눈꺼풀 띠 (2026-11-01 "반쯤 감은 눈꺼풀이 지저분"): 띠는 원본 픽셀이 아니라 맞춘 윗선·아랫선 사이를 채운 깨끗한 한 덩어리(+원본 꼬리 모양)로 다시 만든다. 원본 띠 안의 회색 픽셀(위를 지나는 머리카락 가장자리)은 머리카락 레이어로 옮기고, 띠 자리 안의 머리카락 윤곽은 매끈하게 다듬어 바깥 3px 에 외곽선을 둔다(평소엔 검정 위 검정). `hair_under`(지그재그 머리끝)는 없앴다.
- 띠 밑 채우기(얼굴 레이어): 열마다 띠 바로 위가 피부가 아니면(바깥 눈꼬리의 속눈썹 꼬리가 옆머리 위에 그려진 곳) 머리카락 색으로 채운다. 띠 끝에 닿은 구간만 채우고, 띠 위에서 끝나는 앞머리 끝은 늘리지 않는다(늘리면 떠 있는 꽃잎처럼 보임).
- 눈썹(+둘레 2px) 밑은 주변 15×7 범위에서 머리카락이 많으면 머리카락, 피부가 많으면 피부로 채운다.
- 뒷머리 채움은 턱선까지(목 자리 x 706~802 는 비움), 목덜미 영역의 머리카락 선은 뒷머리로. 런타임에서 목덜미 쪽 뒷머리는 깊이 0·기울기 35% 만 따라감 → 고개를 들거나 기울여도 턱선과 옷깃 사이가 비지 않는다.

## 런타임 구조 (chibi_rig.js)

- 머리: 두개골 구 + 레이어별 깊이 z 로 2.5D 회전(yawMax 22°, pitchMax 12°, roll 0.6). 턱 쪽 깊이를 줄여 고개를 들어도 턱선은 거의 제자리.
- 눈: 눈꺼풀 띠는 열마다 옮기고, 흰자는 띠~아래 경계 사이를 접는다. 홍채·하이라이트·하트 눈은 구멍 없는 눈 열림 마스크(`open_r/l`, 스텐실)로만 잘라 보인다. 거의 다 감으면(k<0.2) 그린 감은 눈 선으로 바꿔 낌. 웃음 눈은 ∩ 로 굽힘.
- 입: 벌림·옆으로·입꼬리에 맞춰 캔버스로 그림(원본 분홍 색). 표정은 `facePose`(face_performance.js) + `rig.expressions[이름].params/add`.
- 몸 (2026-11-01 사용자: "몸이 너무 흐물흐물"): 재킷 밑단 위 상체는 휘지 않는 한 덩어리로, 허리 경첩에서 통째로 기울고 옮겨짐. 다리는 발목을 축으로 곧게 기울어 엉덩이를 받치고, 무릎 굽힘은 세로로 눌림. 원통 깊이로 몸 돌리기, 숨은 가슴·어깨 띠만, 점프·무릎 굽힘 `bodyY`.
- 옷 잘게: 재킷 좌·우 앞판(`jacket_r/l`, 밑단이 따로 흔들림), 옷깃 좌·우(`lapel_r/l`, 앞판보다 앞 → 몸을 돌리면 겹이 드러남), 포켓치프(`psq`), 허벅지 끈(`strap`, 버클 밑에 매달려 흔들림). 옷깃 영역 번호는 regions.npz 기준(`LAPEL`).
- 팔: 원본 T자세를 어깨 축으로 66° 내림(`armRest`). 뿌리는 몸통과 살 이음. 몸·고개 움직임에 2마디 진자로 늦게 따라 흔들리고(팔꿈치도 한 박자 늦게), 숨 쉴 때 살짝 벌어지고 말할 때 들썩이며, 양팔이 서로 다른 박자로 아주 천천히 흔들린다. 손 인사(`handRW/X/Y/Rot`)는 목표 쪽으로 팔을 들고 팔꿈치·손목으로 흔듦 → 떠 있는 손 효과는 쓰지 않음.
- 물리: `cubism_physics.js` 에 physics3 형식 설정(`rig.physics`) — 머리카락 다발 19개(뾰족한 끝마다 뿌리→끝 축, 지연이 다른 진자 6개 HairA~F 를 번갈아 써서 이웃 다발이 엇갈려 흔들림), 바보털, 귀걸이(2마디), 체인, 목걸이, 브로치, 포켓치프, 허벅지 끈, 재킷 좌·우 밑단, 팔(작게). 다발별 최대 각도(`max`, 앞머리 5~6°).
- 얼굴 세부: 입꼬리 좌·우 따로(비웃음), 입 좌우 이동, 오므림(작은 동그라미), 윗입술 올림·윗니, 볼 부풀림(볼 윤곽이 바깥으로), 입을 벌리면 턱이 살짝 내려감, 찡그리거나 웃으면 아래 눈꺼풀 선이 나타나 올라옴, 시선을 내리면 윗눈꺼풀도 내려옴. 트래커 값 mouthFormL/R·mouthX·jawX·cheekPuff·upperUp·eyeSquintL/R·bs_mouthPucker 를 씀.
- 조정값(rig.json tuning): yawMax, pitchMax, rollScale, armRest, armSway, hairPhys, accPhys, bodyBend, wind, gazeX, gazeY.

## 새 머리로 교체 (2026-11-01, 사용자: "새 머리로 바꿔")

- `tools/sdp_newhair.py` → `work/newhair/` + `newhair.json`, `sdp_build.py` 가 원본 머리카락(hair)·바보털·뒷머리 대신 넣음.
- 다발 8개는 뒷머리(1632×2176)를 1508×2000 으로 줄인 같은 그림 틀 → 뒷머리 정렬(0.75배, 131,−86.5)에 틀 비율을 곱해 맞춤.
