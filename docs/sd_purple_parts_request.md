# SD 보라 캐릭터 — 필요한 파츠 목록 (2026-11-01)

지금은 원본 그림 한 장에서 잘라 쓰고, 가려져 안 보이던 부분은 코드가 단색으로 임시로 채우고 있다.
아래 파츠를 받으면 임시 채움을 빼고 그림으로 바꾼다. (사용자 지시: 파츠가 필요하면 요청하고 직접 그리지 않는다.)

## 공통 규격 (가장 중요)
- **원본 그림 위에 따라 그린 것이어야 함.** 2026-11-01 에 받은 파츠는 캐릭터를 새로 그린 그림에서 오린 것이라 머리·팔 비율이 원본과 달라, 겹치면 머리가 커지고 팔이 가늘고 길어져 쓰지 못했음.
  원본(`ref.webp`)을 밑에 깔고 원본 선을 그대로 따라, 가려진 부분만 이어 그리면 됨. 파츠를 모두 겹쳤을 때 원본과 똑같아야 함.

- 원본(`source/vtuber/sd_purple/ref.webp`)과 같은 캔버스 1508×2000, 같은 위치에 겹치게.
- 파츠마다 따로 된 투명 PNG, 또는 레이어가 나뉜 PSD 한 개.
- **가려진 부분까지 끝까지 그린 것** (예: 앞머리에 가려진 이마, 머리카락에 가려진 눈썹 끝).
- 선 굵기·색은 원본과 같게.

## 우선순위 1 — 지금 남은 빈틈·평평한 면을 없앰
| # | 파츠 | 지금 쓰는 임시 방법 | 받으면 좋아지는 것 |
|---|---|---|---|
| 1 | 뒷머리 전체 (머리 뒤쪽부터 목덜미까지) | 어두운 단색 채움 | 크게 돌리거나 기울일 때 얼굴 옆에 보이는 평평한 면이 진짜 머리카락으로 |
| 2 | 얼굴 피부 전체 (이마·관자놀이·볼 윤곽까지, 눈·입·눈썹 없이) | 피부색 단색 채움 + 그린 윤곽선 | 앞머리·눈썹이 움직일 때 드러나는 피부가 자연스럽게 |
| 3 | 귀 양쪽 전체 | 타원 채움 + 그린 윤곽선 | 고개를 돌릴 때 귀 모양이 온전하게 |
| 4 | 목(턱 밑으로 길게, 옷깃 속까지) + 셔츠 깃·재킷 뒤 깃 + 재킷 어깨 윗부분(머리카락에 가려진 곳) | 단색 채움 | 고개를 들거나 돌릴 때 귀 아래·어깨 사이로 배경이 비치는 틈이 사라짐 |

## 우선순위 2 — 디테일

1~4번만 있어도 크게 기울이거나 돌릴 때의 빈틈이 대부분 없어진다.

## 2026-11-01 밤 상태 (전용 세션 뒤)
- 사용자: "그림이 필요하면 그려도 된다, 규칙은 유연하게." → 가려진 곳은 코드로 채우고 그늘·윤곽선을 넣는 것까지 허용. 1~4번의 빈틈은 뒷머리 전체 채움(+윤곽선·얼굴 그늘)·어깨 채움·목 넓힘으로 대부분 메웠다 (구멍 점수 6985 → 1315).
- 그래도 그림이 있으면 더 좋아지는 것: (1) 뒷머리 — 지금은 사용자 뒷머리 그림 + 단색 채움 + 그늘. 고개를 30° 돌리면 얼굴 옆이 평평하게 어두운 면. (2) 옆머리 다발을 따로 (원본 선 그대로, 겹친 부분까지) — 다발끼리 앞뒤로 지나가는 움직임. (3) 45° 옆얼굴 전용 그림(눈·코·입 윤곽) — 지금은 불가.
- 규격은 위와 같음: ref.webp(1508×2000) 위에 원본 선을 그대로 따라 그린 투명 PNG.

## 2026-11-02 — 시트 파일 요청
- 채팅으로 보낸 시트 6장(손 파츠·몸 끝값·눈·표정·고개 각도·머리카락)은 그림만 받아 파일이 없다. PNG 원본을 `source/vtuber/sd_purple/sheets/` 에 넣어 주면 **손 파츠 시트의 손 11쌍을 그대로 오려** 지금 코드로 그린 손 대신 쓸 수 있다 (`tools/sdp_sprites.py` 에 손 자르기 추가 예정). 나머지 시트는 동작 기준으로만 쓰므로 파일이 없어도 됨.

## 2026-11-02 — 지금 꼭 필요한 그림 (우선순위 순, 사용자 질문에 답한 목록)
1. **손 파츠 시트 PNG 원본** (채팅으로 보낸 그 시트). 투명 배경이면 가장 좋고, 검은 배경이어도 됨. 손 하나가 300px 이상이면 충분. → 코드로 그린 손을 진짜 그림으로 교체.
2. **옆으로 돌린 얼굴 2장 (왼쪽 45°, 오른쪽 45°)**: 원본과 같은 크기·같은 머리 위치로, 머리카락·얼굴·귀·귀걸이까지. → 지금 25°까지만 되는 고개 돌리기를 시트 '좌측 끝/우측 끝'처럼.
3. **뒷머리 전체 (ref.webp 위에 따라 그린 1508×2000 투명 PNG)**: 앞머리·얼굴에 가려진 부분까지. → 돌리거나 기울일 때 얼굴 옆의 평평한 면이 진짜 머리카락으로.
4. **옆머리·앞머리 다발 분리 (같은 규격, 다발마다 PNG 하나, 겹친 부분까지 완전하게)**: 원본 선 그대로. → 다발이 서로 앞뒤로 지나가는 머리카락 움직임.
5. (선택) 내린 팔 — 위팔·아래팔·손 따로, 원본 소매 그대로. 지금은 T자세 팔을 돌려 쓰고 있어 어깨 이음새가 약간 어색.
공통: 1~5 중 2~5 는 ref.webp(1508×2000)를 밑에 깔고 **원본 선을 그대로 따라** 그린 것이어야 함(겹치면 원본과 똑같아야 함). 새로 그린 캐릭터에서 오린 것은 비율이 달라 못 씀. 받는 곳: `source/vtuber/sd_purple/sheets/`.
